# CMPG325-2026— Mmala Courier Services Network Project

Individual semester project for CMPG 325 (Computer Networks), North-West University.

**Client:** Mmala Courier Services (Rustenburg) — Logistics
**Assigned challenge:** Inter-VLAN Routing (L3 switch / SVI)
**Addressing block:** 172.30.22.0/23

## Project Overview
This repository documents the design, configuration, and testing of a
segmented VLAN network for Mmala Courier Services, addressing the
client's design constraint (printer sharing must cross departments,
file sharing must not) and Change Request CR7 (CCTV traffic segmentation).
